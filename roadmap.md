# 🗺️ Roadmap

## Objetivo

Este repositório foi desenvolvido para consolidar conhecimentos práticos exigidos em vagas de Desenvolvedor Backend Júnior utilizando Node.js.

Todo o conteúdo foi organizado para simular a evolução natural de um desenvolvedor em um ambiente profissional, desde os fundamentos da linguagem até a construção de uma aplicação completa utilizando boas práticas de arquitetura, testes, documentação e observabilidade.

---
